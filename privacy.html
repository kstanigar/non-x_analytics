Privacy Policy

Standing Tiger  ·  Last updated: June 2026

1. Information We Collect

The NON-X Analytics Dashboard itself does not collect personal information from visitors. It is a read-only display of aggregated game analytics data.

The underlying NON-X game collects anonymized gameplay events through Google Analytics 4 (GA4), including:

  • Session identifiers (anonymized)
  • Device category (desktop or mobile)
  • Game events (game start, boss encounters, game outcome)
  • A/B test group assignments (music, movement)

No names, email addresses, or personally identifiable information are collected or displayed.

2. How We Use It

Aggregated analytics data is used solely to understand gameplay patterns and improve the NON-X game experience. Data displayed on this dashboard is used for portfolio and research purposes only.

3. Third-Party Services

This dashboard uses the following third-party services:

  • Google Analytics 4 — anonymized event collection for the NON-X game. Subject to Google's Privacy Policy.
  • AWS Lambda + API Gateway — serverless API that serves aggregated data to this dashboard. No user data is stored or logged beyond standard AWS CloudWatch metrics.
  • Google BigQuery — data warehouse for historical GA4 export. Access is read-only and restricted to the Standing Tiger service account.

4. Data Retention

GA4 event data is retained according to Google's standard retention policies (14 months by default). Aggregated data cached by the API is held in memory for up to 24 hours and is not persisted to disk or a database.

5. Your Rights

Since no personal data is collected from dashboard visitors, there is no personal data to access, correct, or delete. If you have questions about GA4 data collected through the NON-X game, you may contact us below.

6. Contact

Privacy questions can be directed to contact@standingtiger.com.
