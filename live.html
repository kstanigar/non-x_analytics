Looker Studio Setup Guide
Step 1 — Register GA4 Custom Dimensions
Go to GA4 Admin → Property → Custom Definitions → Custom Dimensions → Create. Register all of these as event-scoped dimensions:
Parameter Name Scope Description Used In Events
ab_music_group Event Music A/B cohort — 'music_on' or 'music_off' All 16 events
music_variant Event Actual music state at event time All in-game events
platform Event 'desktop' or 'mobile' All in-game events
level_number Event Level reached (1–12) wave_reached
phase Event 'green' / 'red' / 'purple' difficulty phase wave_reached, player_death
level_reached Event Highest level before death player_death
boss_id Event Boss number: 1, 2, or 3 boss_attempt, boss_defeated
visit_count Event Lifetime visit number returning_user
is_replay Event true = Play Again, false = fresh game_start
games_played Event Lifetime game count at event time game_start, survey_submitted
instagram_provided Event true/false — handle submitted leaderboard_submit
powerup_type Event 'health', 'double_laser', 'shield' powerup_collected
Also register these as Custom Metrics (numeric): session_duration_seconds, score
Step 2 — Calculated Fields (Looker Studio Syntax)
Create these in your Looker Studio data source under Add a field → Calculated field:
PLAYS
SUM(CASE WHEN event_name = "game_start" THEN event_count ELSE 0 END)
WINS
SUM(CASE WHEN event_name = "player_won" THEN event_count ELSE 0 END)
DEATHS
SUM(CASE WHEN event_name = "player_death" THEN event_count ELSE 0 END)
WIN RATE
SAFE_DIVIDE( Wins, Plays )
BOSS 1 DEFEATS
SUM(CASE WHEN event_name = "boss_defeated" AND boss_id = 1 THEN event_count ELSE 0 END)
BOSS 1 CONVERSION
SAFE_DIVIDE( Boss1Defeats, Plays )
BOSS 2→3 CONVERSION
SAFE_DIVIDE( Boss2Defeats, Boss1Defeats )
LEADERBOARD RATE
SAFE_DIVIDE( LeaderboardSubmits, Wins )
